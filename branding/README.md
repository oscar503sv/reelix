# Reelix — identidad visual

| Archivo | Uso |
|---|---|
| `reelix-dark.svg` | **Ícono oficial** (instalado como `data/icons/hicolor/scalable/apps/io.github.oscar503sv.Reelix.svg`). |
| `reelix-light.svg` | Variante clara, para fondos oscuros o material promocional. |
| `reelix-accent.svg` | Variante de acento (violeta), alternativa. |
| `reelix-symbolic.svg` | Ícono simbólico de GNOME (instalado como `…-symbolic.svg`). |
| `png/` | Exportaciones de las tres variantes a 16, 24, 32, 48, 64, 128, 256 y 512 px. |

Paleta: lavanda `#F0E9FF → #B4A7FF → #7778EE`, rojo de grabación
`#FF747B → #F52F53`, fondo `#30364C → #141724`.

Los íconos que instala la app viven en `data/icons/` con el ID
`io.github.oscar503sv.Reelix`; si cambias el diseño aquí, copia también allí
la variante oscura (SVG y PNG).
